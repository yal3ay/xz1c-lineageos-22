# Security Policy

## Supported versions

Only the current unofficial LineageOS 22.2 build for the Sony Xperia XZ1
Compact SO-02K (`lilac_dcm`) is supported. Older builds are not supported.

## Reporting a vulnerability

Please use **GitHub Private vulnerability reporting**:

1. Open the repository on GitHub.
2. Go to **Security** -> **Advisories**.
3. Click **Report a vulnerability**.

Do **not** open a public issue for an unfixed vulnerability.

Please include the device model (SO-02K), the build date and fingerprint, the
reproduction steps, and relevant logs. Remove personal data, device serial
numbers, Wi-Fi credentials, tokens, and signing material before uploading.

## What to expect

This is a volunteer, unofficial project. We do not promise a response time, a
bug bounty, or a fix deadline. We will read the report, keep it confidential
while it is investigated, and coordinate disclosure after a fix is available.
